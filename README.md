# 族谱查看器

一个**单文件、离线、免安装**的中文族谱（家谱）编辑与查看工具。基于 Python Tkinter 开发，支持从 Word/WPS `.doc` 老族谱解析人物关系，也支持从零新建族谱，并以 `.json` 文件保存、分享。

> 软件不绑定任何家族 —— 每份族谱是一个独立的 `.json` 文件，可以直接发给别人继续编辑。

## ✨ 功能特性

- **全谱树状展示**：按世代分层的文本树，一眼看清整个家族脉络
- **图形世系图**：卡片式吊线图，世代配色、卡片宽度自适应、左右式/上下式双布局
  - 单击卡片：主窗口显示人物详情
  - 双击卡片：只看此人分支
  - Ctrl+滚轮缩放、一键适宽、导出高清 PDF（300 DPI）
- **智能关系推算**：子女/兄弟姐妹由 `father`/`mother` 字段自动反推，无需手工维护
- **互称查询**：输入任意两人，自动计算"他该叫她什么、她该叫他什么"（称呼可在编辑菜单自定义，随族谱文件保存）
- **完整成员编辑**：姓名/字/别名/排行/生卒日期/在世状态/配偶/父母/照片/备注，已去世自动显示享年
- **入赘（赘婿）支持**：赘婿自动挂到岳父关系网，兄弟姐妹标注（妻子）/（丈夫）
- **修订信息**：记录修订人员、修订日期与备注，随族谱保存
- **语音信息**：每位成员可挂多条语音（wav/mp3 等，随 JSON 保存，走 Windows MCI 播放，零额外依赖）
- **查找/替换、成员列表右键菜单、快捷键**（Ctrl+S 保存 / Ctrl+N 新增 / Ctrl+E 编辑）

## 🚀 快速开始

### 方式一：直接使用 EXE（推荐）

从 [Releases](../../releases) 下载 `族谱查看器.exe`，双击运行即可，**完全离线**。

EXE 内置一份「明朝皇帝世系」示例族谱（只读），启动即可浏览。可通过 `文件 → 打开示例族谱（明朝）` 查看，或用 `文件 → 打开族谱` 载入自己的 `.json` 文件，`文件 → 新建族谱` 从零开始。

### 方式二：源码运行

需要 Python 3.8+（Windows 自带 tkinter）：

```bash
git clone https://github.com/<你的用户名>/<仓库名>.git
cd <仓库名>
python 族谱查看器.py
```

可选依赖（按需安装，不装也能跑）：

```bash
pip install Pillow    # 照片显示 与 导出PDF 功能需要
pip install olefile   # 仅解析老式 .doc 族谱文件时需要
```

### 打包成 EXE（Windows）

```bash
# 双击 打包.bat，或命令行执行：
打包.bat
```

脚本会自动定位 Python、检查并安装 PyInstaller、构建多分辨率图标，完成后在 `dist_new/` 生成 `族谱查看器.exe`。

## ⌨️ 命令行用法

```bash
python 族谱查看器.py               # 启动图形界面（自动读取上次打开的族谱）
python 族谱查看器.py 某族谱.json    # 直接打开指定族谱文件
python 族谱查看器.py --test       # 仅解析并打印统计信息（无界面）
python 族谱查看器.py --regen      # 强制从 .doc 重新解析并刷新 genealogy.json
```

## 📁 数据格式

每份族谱就是一个 JSON 文件，结构简单，可以手工编辑：

```jsonc
{
  "rev_info": { "revisers": "张三", "date": "2026-10-13", "notes": "第五次修订" },
  "persons": [
    {
      "name": "张三",
      "gender": "男",
      "birth_year": 1950,
      "father": "张三之父",          // 子女/兄弟姐妹关系由此自动反推
      "mother": "某氏",
      "spouse": "李四",
      "birth_order": 1,             // 排行，用于兄弟姐妹长幼称呼
      "deceased": true,
      "death_year": 2020,
      "ru_zhui": false,             // 入赘标记（赘婿为 true）
      "adopted": false,             // 养子女标记
      "burial": "东山南麓",
      "voices": [ { "name": "口述", "ext": "mp3", "data": "<base64>" } ]
    }
  ]
}
```

要点：

- **只填 `father`/`mother` 即可**，子女列表、兄弟姐妹、世代层级全部自动算出
- 称谓表（称呼设置）与修订信息也保存在同一文件里，发给谁都是同一套称呼
- `lastfile.txt` 仅记录上次打开的文件路径，删除不影响族谱数据

## ❓ 常见问题

**Q：老族谱是 Word 文档，怎么导入？**
把 `.doc` 文件放到程序目录，运行 `python 族谱查看器.py --regen` 自动解析生成 `genealogy.json`（需安装 `olefile`）。解析结果会同时生成 `genealogy.txt` 底本，方便人工核对修改后再次解析。

**Q：为什么我的 EXE 只显示示例？**
EXE 内置一份「明朝皇帝世系」只读示例，启动即展示。通过 `文件 → 打开族谱` 载入自己的 `.json`，或 `文件 → 新建族谱` 从零开始。

**Q：各地称呼不一样怎么办？**
`编辑 → 称呼设置` 里可以自定义全部亲属称谓，随族谱文件一起保存。

**Q：杀毒软件报毒？**
PyInstaller 打包的单文件程序偶尔会被误报，可加入白名单，或自行用 `打包.bat` 从源码构建。
